# Thanks & Acknowledgments

GitH Mobile wouldn't exist without the incredible work of others. This file is a small way of saying thank you to everyone who contributed ideas, code, feedback, inspiration, or simply believed in the project.

---

## 🙏 Special Thanks

### Apple
For the **Human Interface Guidelines** — the design system that inspired every pixel of this app. The bottom sheets, spring animations, SF Pro font, and iOS color palette all trace back to Apple's meticulous work in defining what "native" feels like.

### GitHub
For providing a **world-class REST API** that makes apps like this possible, and for being the platform that inspired this entire project. GitH Mobile exists because GitHub made source control accessible to everyone.

### Next.js & Vercel
For an **incredible framework** and **free, fast hosting**. The App Router, Server Actions, and edge functions made this project a joy to build. Vercel's free tier makes it accessible to everyone.
